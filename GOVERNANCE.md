# Governance

ReviewBus uses a maintainer-led model during 0.x. Akhilesh Gogikar is the initial maintainer and release steward.

Changes are evaluated for scope, reproducibility, inspectability, bias risk, privacy, compatibility, and maintenance cost. New person-level scores, private-repository access, automated assignments, or governance claims require an explicit written decision; they are currently out of scope.

Contributors earn broader review responsibility through sustained accurate work and constructive review. Commit access is not implied by contribution volume. Disagreements return to documented metric definitions and responsible-use constraints; the maintainer decides when consensus is not reached.

Releases require passing CI, updated methodology/changelog, public-only provenance review, and a tagged version. Security fixes may use private review followed by a disclosure that protects reporters and affected people.
