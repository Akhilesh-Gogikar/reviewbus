# Support

ReviewBus is early OSS software maintained on a best-effort basis.

- Usage question or incorrect metric: open a bug report with a minimal synthetic bundle.
- New metric or output improvement: use the feature template and explain responsible-use risks.
- Vulnerability, token detail, private repository metadata, or sensitive person data: use [SECURITY.md](SECURITY.md), never a public issue.

First run `reviewbus --help`, reproduce with `examples/public_repo.json`, and read [troubleshooting](docs/TROUBLESHOOTING.md). There is no guaranteed response time, hosted analysis service, or support for private repositories in 0.x.
